# FreeSSM

FreeSSM is a free and easy to use diagnostic and adjustment tool for **SUBARU®**
vehicles. It currently supports the models LEGACY®, LIBERTY®, OUTBACK®, BAJA®,
IMPREZA®, FORESTER® and TRIBECA® starting with model year 1999 and provides
access to the engine and transmission control units.

## Supported platforms

| Platform | Status |
| --- | --- |
| Linux / X11 | Supported |
| Windows (64 bit) | Supported |
| Windows (32 bit) | **Not supported** — Qt 6 ships no 32-bit Windows binaries |
| Windows XP and older | Untested / unmaintained |
| macOS and other Unix systems | Should be buildable with minor modifications, no official support |

Because FreeSSM is a 64-bit application on Windows, it also needs a **64-bit
J2534 interface library** (see [64-bit builds and J2534](#64-bit-builds-and-j2534-interfaces)).

## Requirements

| Requirement | Version |
| --- | --- |
| Qt | **6.4 or newer** — 6.12 LTS recommended. Qt 4 and Qt 5 are no longer supported. |
| CMake | 3.21 or newer |
| C++ compiler | C++17 — GCC 11+, Clang 14+ or MSVC 2022 |
| tinyxml2 | Bundled (11.0.0); optionally the system copy, 10 or newer |

### Qt packages

Linux distributions usually provide ready-made packages, which should be
preferred. Development packages are needed too, including the Linguist tools
used to build the translations:

```bash
# Debian 12, Ubuntu 24.04 and newer
sudo apt install qt6-base-dev qt6-tools-dev qt6-l10n-tools
```

On other distributions the package names differ, but you need the same two
things: the Qt 6 base development package and the Qt Linguist tools. Qt can
also be downloaded from <https://www.qt.io/download> or the
[Qt online installer](https://www.qt.io/download-qt-installer); there is no need
to install Qt Creator or the Qt sources.

On Windows any 64-bit Qt 6 build works — MSVC 2022 or MinGW-w64 13+. The Qt
runtime libraries are copied next to the executable during installation, so the
application directory is self-contained.

### tinyxml2

The bundled copy in `src/tinyxml2/` is built automatically. On systems that
ship tinyxml2 10 or newer, the distribution copy can be used instead:

```bash
cmake -S . -B build -DFREESSM_USE_SYSTEM_TINYXML2=ON   # needs libtinyxml2-dev
```

## Compilation

Only compilation from the command line is maintained and tested (Qt Creator may
work as well).

### 64-bit builds and J2534 interfaces

FreeSSM is built as a 64-bit application. A J2534 interface library must match:
a 64-bit application can only load a 64-bit interface library. Interfaces that
only exist as 32-bit DLLs can no longer be used — they would require a 32-bit
Qt 6, which does not exist.

### CMake (recommended)

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

If Qt lives in a non-standard location (the official Qt installer or
`aqtinstall`), point CMake at it:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_PREFIX_PATH=/path/to/Qt/6.12.0/gcc_64
cmake --build build -j
```

The three translation files (`FreeSSM_en.qm`, `FreeSSM_de.qm`,
`FreeSSM_tr.qm`) are generated by the build; there is no separate translation
target.

### qmake (fallback, removed in the next release)

The former project file `FreeSSM.pro` is kept for one release. It requires Qt 6
as well and errors out on older versions:

```bash
qmake6 FreeSSM.pro
make release
```

> **The small-resolution UI variant** (`CONFIG+=small-resolution`) is
> unmaintained, does not build, and is not supported.

## Installation

The installation copies the binary together with everything it needs at runtime
— fonts, `background.png`, `definitions/`, `doc/` and the `.qm` translations —
into one flat application directory. FreeSSM resolves all of these relative to
the location of its own executable, so they must not be split up.

```bash
cmake --install build --prefix "$HOME/FreeSSM"
```

Without `--prefix` the files go to `/usr/local`, which is usually not what you
want for a self-contained directory like this one.

On Windows the Qt runtime libraries are deployed into that same directory
automatically, so it can be copied to another machine as-is.

A distributable archive is produced with CPack:

```bash
cpack -G TGZ --config build/CPackConfig.cmake
```

Uninstallation is a plain directory removal:

```bash
rm -rf "$HOME/FreeSSM"
```

> **Note:** when Qt comes from the official installer or `aqtinstall` instead of
> the distribution, the installed binary has no built-in library search path.
> Run it with the Qt library directory in `LD_LIBRARY_PATH`:
>
> ```bash
> LD_LIBRARY_PATH=/path/to/Qt/6.12.0/gcc_64/lib "$HOME/FreeSSM/FreeSSM"
> ```

## Starting FreeSSM

First, switch to the installation directory (see [Installation](#installation)).

```bash
./FreeSSM        # Linux
freessm          # Windows
```

Additional command line options can be appended. For a full list of supported
options and their descriptions, start FreeSSM with `-h` (or `--help`):

```console
$ ./FreeSSM -h
=> prints help text (list of supported command line options)

$ ./FreeSSM -c transmission -f mbssws -p selectionfile="/home/users/myMBSWselection_4.list" autostart
=> starts directly into the transmission control unit dialog, selects reading of
   measuring blocks and switches, loads the MB/SW selection file
   "/home/users/myMBSWselection_4.list" and starts reading immediately
```
